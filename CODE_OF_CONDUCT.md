# Code of conduct

Linea adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to every project space: issues, pull
requests, discussions and any other channel run for the project, and to
anyone representing the project elsewhere.

## Reporting

Report unacceptable behavior in an issue, pull request or comment with
GitHub's **Report content** option (the `...` menu on the item), and choose to
report it to the repository maintainers. Reports are handled confidentially.
The maintainers enforce the code of conduct following the Covenant's
enforcement guidelines.
